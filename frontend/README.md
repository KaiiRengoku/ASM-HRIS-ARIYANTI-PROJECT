# ASM HRIS - Frontend

React SPA (TypeScript + Vite + Tailwind CSS + shadcn/ui) untuk Sistem Informasi Kepegawaian ASM Ariyanti.

## Setup

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` - development server
- `npm run build` - build produksi (tsc + vite)
- `npm run lint` - oxlint
